# MatList — Product Brief

> **"วัสดุครบ จบที่ลิสต์เดียว"**
> เครื่องมือทำตารางสเปกวัสดุสำหรับผู้ออกแบบไทย ที่ต่อท่อส่งใบขอราคา (RFQ) ตรงถึงผู้ขายในตัว

---

## 1. MatList คืออะไร

MatList คือแพลตฟอร์มที่เชื่อม "โต๊ะทำงานของผู้ออกแบบ" เข้ากับ "ผู้ขายวัสดุ" ด้วยข้อมูลสเปกที่เป็นมาตรฐานเดียวกัน

หัวใจของระบบคือ **Material List** — ตารางสเปกวัสดุของโปรเจกต์ (พื้นห้องนั่งเล่นใช้อะไร ผนังห้องน้ำใช้อะไร กี่ตารางเมตร) ซึ่งเป็นเอกสารที่ผู้ออกแบบทุกคน "ต้องทำอยู่แล้ว" ในทุกโปรเจกต์ แต่วันนี้ยังทำกันใน Excel ที่ไม่เชื่อมกับอะไรเลย

MatList เปลี่ยนตารางนั้นให้มีชีวิต:
- เลือกวัสดุจาก**คลังวัสดุกลาง** (เทียบสเปก-ราคาได้ทันที ไม่ต้องไล่โทรถาม)
- กดปุ่มเดียว **ส่งใบขอราคา/ขอตัวอย่าง** ไปหาผู้ขายที่เกี่ยวข้องทุกเจ้า
- ราคาที่ตอบกลับ **เด้งกลับเข้าตารางแถวเดิม** เทียบกันเห็น ๆ เลือกผู้ชนะ ปิดดีล
- ปลายทางออกเป็น **Spec Book PDF** ส่งลูกค้า/ผู้รับเหมาได้ทันที

**จุดยืนสำคัญ: เครื่องมือต้องมีค่าตั้งแต่ยังไม่มีผู้ขายสักราย** — ต่อให้ไม่มีใครตอบราคา ตารางสเปก + คลังวัสดุ + Spec Book ก็แทน workflow เดิมได้สมบูรณ์ นี่คือกลยุทธ์แก้ปัญหา chicken-and-egg ของ marketplace

## 2. Value Proposition (คุณค่าที่ส่งมอบ แยกตามผู้ใช้)

### ฝั่งผู้ออกแบบ (Designer) — "ประหยัดเวลา และตัดสินใจได้ดีกว่า"
| ปัญหาเดิม | MatList แก้ให้ |
|---|---|
| ทำตารางสเปกใน Excel ซ้ำ ๆ ทุกโปรเจกต์ | ตารางสำเร็จรูป + template + นำเข้าจาก Excel เดิมได้ |
| หาวัสดุต้องเปิด catalog เป็นสิบเล่ม / ไล่ถามเซลส์ | คลังวัสดุค้น-กรอง-เทียบได้ในที่เดียว เปิดดูได้โดยไม่ต้องสมัคร |
| ขอราคาทีละเจ้า ทางไลน์/โทร ตกหล่น ตามยาก | RFQ กดครั้งเดียวถึงทุกเจ้าที่เกี่ยวข้อง มีสถานะ + เดดไลน์ตามให้ |
| ราคาที่ได้มากระจัดกระจาย เทียบยาก | ตารางเทียบราคาข้างกันในแถวเดิมของสเปก |
| ทำ mood board / spec book แยกอีกโปรแกรม | Material Board + Spec Book PDF ในตัว |

### ฝั่งผู้ขายวัสดุ (Seller) — "lead คุณภาพสูง ในจังหวะที่ถูกต้อง"
| ปัญหาเดิม | MatList แก้ให้ |
|---|---|
| ไม่รู้ว่าโปรเจกต์ไหนกำลังจะสเปกของตัวเอง | RFQ วิ่งเข้า inbox เมื่อผู้ออกแบบเลือกสินค้าเป็นตัวเลือกจริง — เป็น lead ตอน "กำลังตัดสินใจ" ไม่ใช่โฆษณาหว่าน |
| เอาสินค้าเข้าระบบไหน ๆ ก็เหนื่อย | นำเข้าจาก Excel/CSV/PDF catalog — ระบบดึงข้อมูลให้อัตโนมัติ |
| แข่งกันด้วยงบโฆษณา ไม่ใช่คุณภาพข้อมูล | อันดับผลค้นหามาจาก "ความตรงสเปก + ความครบของข้อมูล" เท่านั้น ทุกเจ้าแข่งกันที่ของจริง |
| ไม่รู้ประสิทธิภาพทีมขายตัวเอง | Dashboard: เวลาตอบเฉลี่ยของตัวเอง vs ค่าเฉลี่ยแพลตฟอร์ม (aggregate เท่านั้น) |

### สิ่งที่ทำให้เลียนแบบยาก (Moat)
1. **ความเป็นกลางคือสินค้า** — เราขายความไว้ใจของผู้ออกแบบให้ผู้ขาย พังฝั่งเดียวพังทั้งระบบ จึงเป็นกติกาเหล็ก ไม่ใช่นโยบายที่ต่อรองได้
2. **Workflow ครบวงจร** — คู่แข่งที่เป็น catalog อย่างเดียว หรือ e-commerce อย่างเดียว ไม่ได้อยู่ในจังหวะ "กำลังสเปก" ซึ่งเป็นจุดที่การตัดสินใจซื้อเกิดจริง
3. **ข้อมูลสเปกเชิงโครงสร้าง** — ทุกวัสดุมี field มาตรฐาน (ราคา หน่วย มอก. lead time ประกัน) ยิ่งใช้ยิ่งหนา เป็นฐานของ VE Finder และฟีเจอร์ฉลาด ๆ ในอนาคต

## 3. Vision / Mission

**Vision (ภาพฝัน):**
> เป็นโครงสร้างพื้นฐานของการเลือกและจัดซื้อวัสดุในงานออกแบบ-ก่อสร้างของไทย — ทุกสเปกที่เขียนขึ้นในประเทศนี้ วิ่งผ่านระบบที่โปร่งใส เทียบกันได้ และเป็นธรรมกับทุกฝ่าย

**Mission (พันธกิจ):**
> ทำให้ผู้ออกแบบทุกสายเลือกวัสดุได้เร็วขึ้นและมั่นใจขึ้น และทำให้ผู้ขายทุกขนาด — จากแบรนด์ใหญ่ถึงโรงอิฐท้องถิ่น — เข้าถึงโปรเจกต์ได้ด้วยคุณภาพข้อมูล ไม่ใช่งบโฆษณา

**หลักการที่ไม่ต่อรอง (กติกาเหล็ก 5 ข้อ):**
1. ผลค้นหาเรียงตามความตรงสเปกเท่านั้น — ไม่มีการซื้ออันดับ ไม่มีโฆษณาแฝง
2. ราคา lead เดียวเท่ากันทุกเจ้า — ไม่มีจ่ายเพิ่มเพื่อขึ้นก่อน
3. ขายข้อมูลเฉพาะภาพรวม (aggregate) — ไม่ขายข้อมูลรายออฟฟิศ/รายโปรเจกต์เด็ดขาด
4. ผู้ขายเห็นบริบทสเปก แต่ไม่เห็นข้อมูลติดต่อผู้ออกแบบจนกว่าผู้ออกแบบตอบกลับเอง
5. การติดต่อ contact ภายนอกต้องผ่านการตรวจ PDPA ก่อนเสมอ

## 4. ผู้ใช้ (Users)

### ฝั่งเลือกวัสดุ — "ผู้ออกแบบทุกสายในไทย"
ไม่จำกัดแค่สถาปนิก: **สถาปนิก · นักออกแบบภายใน · มัณฑนากร · ภูมิสถาปนิก · Industrial designer · Graphic/Exhibition designer** และใครก็ตามที่ต้องเลือกวัสดุให้โปรเจกต์

ตัวอย่าง persona:
- **"พี่แพร" เจ้าของสตูดิโอออกแบบภายใน 6 คน** — ทำบ้านและร้านอาหาร 8–12 โปรเจกต์/ปี ปวดหัวกับการตามราคาทางไลน์ที่สุด → ใช้ RFQ + ตารางเทียบราคาเป็นหลัก อัปเกรด Studio เพื่อ template/ชุดวัสดุที่ใช้ซ้ำ
- **"ต้น" สถาปนิกจูเนียร์ในออฟฟิศกลาง** — โดนมอบหมายทำสเปกชีท → เริ่มจากดูคลังวัสดุฟรีโดยยังไม่สมัครด้วยซ้ำ แล้วค่อยดึงทีมเข้ามาใช้ทั้งออฟฟิศ (bottom-up adoption)
- **ลูกค้า/ผู้รับเหมา (ทางอ้อม)** — รับ Spec Book PDF ที่อ่านง่าย ครบ อ้างอิงได้

**Role ในระบบ:** owner / manager (แก้ได้) / viewer (ดูอย่างเดียว) — รองรับการทำงานเป็นทีม

### ฝั่งขายวัสดุ — "ผู้ขายทุกขนาด"
- **แบรนด์ใหญ่/ตัวแทนจำหน่าย** — ทีมขายหลายคน (owner / sales ตอบ RFQ / content ดูแลข้อมูลสินค้า) ใช้ inbox + SLA + performance dashboard
- **ผู้ผลิตรายเล็ก/ท้องถิ่น** (โรงอิฐ โรงหิน ช่างผ้า) — จุดขายของเราคือ "แข่งด้วยข้อมูล ไม่ใช่งบ" รายเล็กที่ข้อมูลครบจึงชนะได้
- **ทีมข้อมูลสินค้า** — มีเครื่องมือนำเข้าจากไฟล์ + คะแนนความครบของข้อมูล (completeness) บอกชัดว่าเติมอะไรแล้วอันดับดีขึ้น

### โมเดลรายได้ (สรุป)
- **รายได้หลักมาจากฝั่งผู้ขาย**: จ่ายเพื่อรับ lead (ราคาเดียวทุกเจ้า) + เครื่องมือตอบ/จัดการทีม
- **ฝั่งผู้ออกแบบ freemium**: ใช้ฟรีได้จริง จ่ายเมื่อต้องการของระดับโปร (Pro/Studio — template, ชุดวัสดุ, VE Finder, Revit ในอนาคต)

## 5. Branding

**ชื่อ:** MatList = **Mat**erial + **List** — ตรงตัว จำง่าย สะกดง่ายทั้งไทย/อังกฤษ และชี้ไปที่หัวใจของ product คือ "ลิสต์วัสดุ"

**Tagline:** "วัสดุครบ จบที่ลิสต์เดียว" (หน้าแรกใช้คู่กับ "ทุกวัสดุ จบในลิสต์เดียว")

**บุคลิกแบรนด์ (Brand Personality):**
- **มืออาชีพแต่เป็นกันเอง** — คุยภาษาเดียวกับคนหน้างาน ไม่ใช่ภาษาการตลาด
- **ตรงไปตรงมา** — เหมือนกติกาของระบบ: โปร่งใส ไม่มีวาระซ่อน
- **เบา เร็ว ไม่เกะกะ** — เป็น "เครื่องมือช่าง" ที่หยิบใช้แล้ววางได้ ไม่ใช่แอปที่แย่งเวลา
- **สองภาษาโดยกำเนิด** — ไทยเป็นหลัก อังกฤษเต็มรูปแบบ (รองรับออฟฟิศอินเตอร์)

**เสียงของแบรนด์ (Tone of Voice):**
- ใช้คำที่วงการใช้จริง: "สเปก", "ขอราคา", "BOQ", "มอก.", "lead time"
- ประโยคสั้น บอกผลลัพธ์ก่อน แล้วค่อยอธิบาย
- ความปลอดภัย/ความเป็นส่วนตัวพูดชัดในจุดที่เกี่ยว (เช่น 🔒 ใต้ปุ่มส่ง RFQ)

**ข้อความหลักที่ใช้สื่อสารซ้ำ ๆ (Key Messages):**
1. "เปิดมาก็เห็นสินค้าเลย — ไม่ต้องสมัครก็ดูได้" (ความ open)
2. "เรียงตามความตรงสเปกเท่านั้น ไม่มีการซื้ออันดับ" (ความเป็นกลาง — พิมพ์ไว้ใต้ช่องค้นหาจริง ๆ)
3. "ราคาวิ่งกลับเข้าตารางเอง" (ประหยัดเวลา)
4. "รายเล็กชนะได้ด้วยข้อมูลที่ครบ" (แฟร์กับผู้ขาย)

## 6. CI — Corporate Identity (อัตลักษณ์ที่ใช้อยู่จริงในระบบ)

### สี (Color Palette)
| บทบาท | สี | โค้ด |
|---|---|---|
| **สีแบรนด์หลัก** | ส้มอิฐ (Brick Orange) | `#F4632A` |
| สีแบรนด์อ่อน (พื้นหลัง chip/ไฮไลต์) | ส้มนวล | `#FFF1EA` |
| ตัวอักษรหลัก | น้ำเงินเข้มเกือบดำ (Ink) | `#1F2430` |
| ตัวอักษรรอง / เส้น | เทากลาง / เทาอ่อน | `#6B7280` / `#ECEDF0` |
| พื้นหลังเพจ / การ์ด | เทาอ่อนมาก / ขาว | `#F5F6F8` / `#FFFFFF` |
| สถานะ: สำเร็จ/ยืนยัน | เขียว | `#12A150` |
| สถานะ: เตือน/เลยกำหนด | ส้มน้ำตาล | `#B45309` |
| สถานะ: ได้ราคาแล้ว | ฟ้าเข้ม | `#0B6BAE` |
| สถานะ: ข้อมูล/กำลังดำเนินการ | ม่วงน้ำเงิน | `#4F46E5` |

*เหตุผลของส้มอิฐ:* มาจากวัสดุจริง (อิฐ ดินเผา ไม้) — อบอุ่น มีพลัง แต่ไม่แสบตา และตัดกับโทนเทา-ขาวของ UI ทำให้ปุ่ม action เด่นชัดเจน

### ตัวอักษร (Typography)
- **Noto Sans Thai** เป็นหลัก (fallback: Inter / system-ui) — อ่านง่ายทั้งไทย-อังกฤษ น้ำหนักครบ ฟรีและเปิด
- เอกสาร PDF (Spec Book) ใช้ **Sarabun** — ฟอนต์ราชการไทยที่พิมพ์แล้วดูเป็นทางการ
- ขนาดฐาน 17px — ใหญ่กว่ามาตรฐานเล็กน้อยเพื่อการอ่านสบายตามที่ผู้ใช้ต้องการ

### รูปทรงและองค์ประกอบ (Visual Language)
- **มุมโค้ง + ปุ่มทรงแคปซูล (pill)** — ดูเป็นมิตร ทันสมัย
- **การ์ดขาวบนพื้นเทาอ่อน + เงานุ่ม** — ลำดับชั้นชัดโดยไม่ต้องใช้เส้นหนัก
- **Swatch วัสดุ** — สี่เหลี่ยมสีพร้อม texture ตามตระกูลวัสดุ (ลายไม้ ลายหิน ลายกระเบื้อง ฯลฯ) เป็นเอกลักษณ์ภาพของ MatList จนกว่าจะมีรูปถ่ายจริง
- **ไอคอนอีโมจิเชิงหน้าที่** — 📨 ขอราคา · 📕 Spec Book · 🧰 เครื่องมือ Studio · 🔒 ความเป็นส่วนตัว: สื่อสารเร็วโดยไม่ต้องออกแบบไอคอนเซ็ตใหม่ (ช่วงเริ่มต้น)
- **สถานะเป็นป้ายสี (StatusChip)** — ทั้งระบบใช้ภาษาสีเดียวกัน: เขียว=จบ/ยืนยัน, ฟ้า=ได้ราคา, ส้มน้ำตาล=รอ/เลยกำหนด

### โลโก้ (สถานะปัจจุบัน)
ยังใช้ **wordmark ตัวอักษร "MatList"** สีส้มอิฐ ตัวหนา — เพียงพอสำหรับช่วง MVP
*แนะนำขั้นถัดไป:* ทำโลโก้จริง 1 ชุด (wordmark + สัญลักษณ์ย่อสำหรับ favicon/app icon — แนวคิดที่เข้ากับแบรนด์: ช่องตาราง/swatch สี่เหลี่ยมมุมโค้งที่เรียงเป็นลิสต์) พร้อม brand guideline สั้น ๆ 1 หน้า

## 7. สถานะ product วันนี้ (กรกฎาคม 2026)

**พร้อมใช้แล้ว:** คลังวัสดุสาธารณะ (1,000+ รายการเดโม่ / filter / 5 view modes) · Material List ครบวงจร (options เทียบข้างกัน, RFQ, ตารางเทียบราคา, เลือกผู้ชนะ, แชท) · Material Board ลากวาง · Spec Book PDF · Template/ชุดวัสดุ (Studio) · ฝั่งผู้ขายครบ (inbox+SLA, จัดการสินค้า, นำเข้าจากไฟล์/PDF, แบรนด์, ทีม, performance) · ระบบความปลอดภัย/PDPA พื้นฐาน · TH/EN เต็มระบบ

**รอปัจจัยภายนอก:** ระบบชำระเงินจริง (รอเลือก Omise/2C2P) · ส่ง RFQ ออกนอกระบบทาง LINE/email (รอ credentials + ทนายตรวจ PDPA) · เอกสารกฎหมาย (รอทนาย) · ข้อมูลผู้ขายจริง

**แนะนำให้ทำต่อ:** รูปภาพสินค้าจริง → ข้อมูลผู้ขายจริง 20–30 ราย → VE Finder → mobile polish
